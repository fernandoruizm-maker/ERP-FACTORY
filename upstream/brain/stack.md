# Stack de la factoría

Estado: propuesta inicial; no describe un producto existente.
Referencia ejecutable: Python 3.11+ y SQLite con biblioteca estándar.
Servicio objetivo: API HTTP Python, PostgreSQL para múltiples workers,
Temporal para ejecución durable y adaptadores de agentes intercambiables.
ORM objetivo: SQLAlchemy; migraciones: Alembic.
El producto construido conserva su propio framework, ORM y base de datos.
Cambiar el stack exige un ADR aprobado.
